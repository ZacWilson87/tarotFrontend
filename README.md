# Tarot Card App Frontend

Welcome to the **Tarot Card App Frontend**, a user interface built with **Next.js**, **TypeScript**, and **Tailwind CSS**. This frontend application connects to the Go-based backend API, offering users an engaging experience for tarot card readings, deck customization, and future AI-generated tarot card art.

---

## About the Project

The frontend serves as the visual and interactive layer of the **Tarot Card App**, where users can:

- Perform tarot card readings using various spreads.
- Manage and customize their own tarot decks. (WIP)
- View and download AI-generated tarot card art (coming soon).

This project emphasizes a clean, user-friendly design while ensuring fast performance and seamless integration with the backend.

---

## Features

- **User Authentication**: (WIP)
  - Secure login and registration powered by Auth0.
  - Persistent sessions for a smooth user experience.

- **Tarot Readings**:
  - Interactive UI for selecting spread types and interpreting results.
  - Real-time results fetched from the backend API.

- **Deck Management**: (WIP)
  - Create and customize tarot decks with an intuitive interface.

- **Responsive Design**:
  - Fully mobile-friendly layout for on-the-go users.

## Technology Stack

- **Framework**: Next.js
- **Language**: TypeScript
- **Styling**: Tailwind CSS for rapid design and consistent styling
- **HTTP Requests**: Axios for API communication
